# Ziyuan Zheng academic homepage

This folder is the canonical source for the public GitHub Pages site.

- `index.html`, `style.css`, and `script.js` contain the page.
- `ziyuan-zheng.jpg`, `og.jpg`, and `favicon.svg` are local assets.
- `robots.txt` and `sitemap.xml` support indexing.
- Run `node scripts/build-single-page.mjs` from the workspace root to rebuild the optional single-file fallback in `github-pages-single/index.html`.

The public URL is <https://zhengziyuan.github.io/ziyuanzheng.github.io/>.
